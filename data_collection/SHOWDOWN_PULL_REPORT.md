## Bug found and fixed during this pull

Showdown's species names use a **curly apostrophe** (`’`, U+2019) in `Farfetch’d` and
`Sirfetch’d`, not the plain ASCII apostrophe (`'`, U+0027) the task's worked example used.
The first draft of the slugifier only stripped the ASCII apostrophe, so it computed
`farfetch-d` / `sirfetch-d` instead of `farfetchd` / `sirfetchd`. Fixed by stripping both
apostrophe variants (plus the left-curly `‘` for safety). Confirmed correct in the committed
data: `pokemon.json` has `farfetchd` and `farfetchd-galar` (matching the pre-existing
convention already used for similar ids), not `farfetch-d`. Move names use a plain ASCII
apostrophe instead (e.g. `King's Shield`) — both are handled by the same fixed regex.

from the old PokeAPI-style values. **621 of the 622 moves that existed in the old file

## Move that appears in the OLD data but not in the new pull — investigated

**`vice-grip`** — this is a real, official rename. Nintendo/Game Freak renamed the move
"Vice Grip" to "**Vise Grip**" starting in Gen 9 (trademark reasons), and Showdown's data
reflects the current name. New id: **`vise-grip`**. Not a data-loss bug — any code
referencing `vice-grip` should be updated to `vise-grip`.
